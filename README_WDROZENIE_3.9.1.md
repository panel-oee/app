# Wdrożenie Panel OEE 3.9.1

1. Wgraj całą zawartość paczki do katalogu GitHub Pages.
2. Podmień `panel.html`, `config_panel.html`, `version.json`, `manifest.webmanifest` i `sw.js`.
3. Wgraj foldery `assets` i `icons`.
4. Po publikacji otwórz aplikację i użyj przycisku „Sprawdź aktualizację”.
5. Nie zmieniaj struktury tabel Supabase ani bucketu `break-sounds`.
